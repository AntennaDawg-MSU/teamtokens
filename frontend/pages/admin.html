🪙 Team Tokens — Admin

Import Teams

CSV columns: team_number, team_name, advisor_1_netid, advisor_2_netid, advisor_3_netid
Advisor columns are optional — leave blank if not needed.

Example:

team_number,team_name,advisor_1_netid,advisor_2_netid,advisor_3_netid
1,Alpha Team,drsmith,,
2,Beta Team,drjones,drwilliams,

Import Student Roster

CSV columns: name, netid, team_number
Import teams first before importing students.

Import Assignments

CSV columns: assignment_number, title, open_date, due_date, token_value, shibboleth

Example:

assignment_number,title,open_date,due_date,token_value,shibboleth
1,Week 1,2024-09-09 00:00:00,2024-09-13 23:59:00,10,BULL2024W1
